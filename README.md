# Portafolio Personal

Este es el código fuente de mi portafolio personal, desarrollado con [Astro](https://astro.build/) y Tailwind CSS. Aquí muestro mi experiencia, proyectos y formas de contacto.

## Instalación

1. **Clona el repositorio:**
   ```sh
   git clone https://github.com/tu-usuario/tu-repo.git
   cd tu-repo
   ```

2. **Instala las dependencias:**
   ```sh
   pnpm install
   ```
   > También puedes usar `npm install` o `yarn install` si prefieres otro gestor de paquetes.

## Modo desarrollo

Para iniciar el servidor de desarrollo y ver el portafolio en tu navegador:

```sh
pnpm dev
```
o
```sh
npm run dev
```

Luego abre [http://localhost:4321](http://localhost:4321) en tu navegador.
